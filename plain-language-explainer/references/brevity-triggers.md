# Brevity Triggers

Read this when checking whether the user asked for a short answer.

## Turkish

- "kısaca", "kısaca anlat", "kısa kes", "kısa tut"
- "özetle", "özet geç", "özetini ver"
- "tek cümleyle", "bir cümlede", "tek satır"
- "uzatma", "detaya girme", "ayrıntıya girme"
- "hızlıca", "çabucak"
- "sadece sonucu söyle", "net söyle", "kısa cevap"

## English

- "shortly", "briefly", "in brief", "in short"
- "keep it short", "keep it brief", "TL;DR", "summarize"
- "one sentence", "one line", "quick answer"
- "just the answer", "bottom line"

## What short mode changes

| Element | Normal | Short mode |
|---|---|---|
| Length | As long as the explanation needs | ~8 lines |
| Example | Required | Still required — exactly one |
| Tables | Allowed when comparing | Not used |
| Code blocks | Allowed when clearest | Not used |
| File paths | Allowed after the sentence | Only if the user must open the file |
| Numbers | Those that carry meaning | At most one |

## What short mode never changes

The example stays. Brevity is bought by cutting background, caveats, and
alternatives — never by cutting the one thing that makes the answer land.

## The opposite signal

"detaylı anlat", "daha ayrıntılı", "in detail", "elaborate" switch on the
opposite: **more examples and smaller steps**. They never mean more jargon,
longer sentences, or a measurement dump.
